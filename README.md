# WS Quiz

Интерактивное приложение для практикумов курса.
Ведущий показывает задачи «что выведет консоль», студенты отвечают, сервер считает очки и строит таблицу рекордов в реальном времени.

---

## Быстрый старт

**Требования:** Node.js 20.6+

```bash
# Установить зависимости
npm install

# Терминал 1 — сервер (порт 3000)
cd server && npx tsx watch --env-file=.env src/index.ts

# Терминал 2 — клиент (порт 5173)
cd client && npm run dev
```

## Три экрана

| Экран | URL | Кто открывает |
|-------|-----|---------------|
| **Ведущий** | `http://localhost:5173/host` | Преподаватель |
| **Студент** | `http://localhost:5173/join` | Каждый студент |
| **Демо** | `http://localhost:5173/present` | Проектор / screen share |

### Ведущий (`/host`)

1. Открыть страницу, ввести токен из `server/.env` → `HOST_TOKEN=dev-token`
2. Выбрать файл вопросов (например `week-09.json`) и конкретный вопрос
3. Нажать **Запустить вопрос** — все студенты и экран получают задачу
4. Смотреть счётчик «Ответили X / Y» в реальном времени
5. Нажать **Завершить раунд** — появляются ответы студентов с кнопками `+1` / `−1` для ручной корректировки оценок
6. Таблица рекордов обновляется автоматически

### Студент (`/join`)

1. Открыть страницу, ввести никнейм → **Войти**
2. Ждать вопроса от ведущего
3. Увидеть код задачи, ввести ответ → **Отправить**
4. После раунда — результат (верно / неверно, очки) и таблица рекордов

### Демо-экран (`/present`)

Страница для проектора или screen share. Не требует авторизации.

- Показывает код текущей задачи с подсветкой синтаксиса
- Таймер-полоса (убывает от `startedAt`, рассчитывается локально — работает при reconnect)
- Счётчик ответов в реальном времени
- Финальный экран с правильным ответом после завершения раунда

## Переменные окружения

**`server/.env`**

```
HOST_TOKEN=dev-token   # токен авторизации ведущего
PORT=3000              # порт сервера (по умолчанию 3000)
```

---

## Добавить вопросы

Вопросы хранятся в `questions/*.json`. Формат:

```json
[
  {
    "id": "w09-01",
    "code": "console.log(1 + '2');",
    "answers": ["12", "'12'"]
  }
]
```

Чтобы сконвертировать Markdown-практикум в JSON:

```bash
npm run md-to-json -- doc/ПРАКТИКУМ-неделя-9.md questions/week-09.json
```

## Структура проекта

```
ws-quiz/
├── server/src/
│   ├── index.ts        — Express + WebSocket, порт 3000
│   ├── session.ts      — GameSession: вопросы, таймер, очки, reconnect
│   ├── handlers.ts     — dispatch WS-сообщений
│   ├── normalizer.ts   — нормализация ответов
│   └── questions.ts    — загрузка JSON
│
├── client/src/
│   ├── pages/
│   │   ├── HostPage.tsx
│   │   ├── JoinPage.tsx
│   │   └── PresentPage.tsx
│   ├── components/
│   │   ├── CodeBlock.tsx   — подсветка через highlight.js
│   │   ├── Timer.tsx       — прогресс-бар от startedAt
│   │   └── Scoreboard.tsx
│   └── hooks/
│       └── useSocket.ts    — WebSocket + auto-reconnect
│
├── shared/
│   └── types.ts        — типы WS-событий (используются и сервером и клиентом)
│
├── questions/
│   └── week-09.json    — вопросы недели 9
│
└── scripts/
    └── md-to-json.ts   — конвертер Markdown → JSON
```
