## Блок 1 — Чистые функции и побочные эффекты

### Задача 1

```js
let base = 100;
const addBase = (n) => n + base;
const a = addBase(5);
base = 200;
const b = addBase(5);
console.log(a, b);
```

<details>
<summary>Ответ</summary>

```
105 205
```

`addBase` читает внешнюю **изменяемую** переменную `base` → функция нечистая: при одинаковом аргументе возвращает разный результат.

</details>

---

### Задача 2

```js
const nums = [1, 2, 3, 4, 5];
const a = nums.slice(1, 3);
const b = nums.splice(1, 2);
console.log(nums.length, a, b);
```

<details>
<summary>Ответ</summary>

```
3 [2, 3] [2, 3]
```

`slice` возвращает копию, не трогая оригинал. `splice` извлекает элементы из `nums` на месте → в `nums` осталось `[1, 4, 5]`.

</details>

---

### Задача 3

```js
const doubled = [1, 2, 3].forEach(x => x * 2);
const mapped  = [1, 2, 3].map(x => x * 2);
console.log(doubled, mapped);
```

<details>
<summary>Ответ</summary>

```
undefined [2, 4, 6]
```

`forEach` всегда возвращает `undefined`, результат колбэка выбрасывается. `map` строит и возвращает новый массив.

</details>

---

### Задача 4

```js
const update = (obj, key, val) => { obj[key] = val; return obj; };
const config = { debug: false };
const next = update(config, 'debug', true);
console.log(config.debug, next === config);
```

<details>
<summary>Ответ</summary>

```
true true
```

Функция мутирует входной объект и возвращает **ту же ссылку** — `next === config`. Чистой такую функцию не назвать.

</details>

---

### Задача 5

```js
const withLog = (fn) => (...args) => {
  const result = fn(...args);
  console.log('result:', result);
  return result;
};
const square = withLog(x => x ** 2);
square(3);
square(3);
```

<details>
<summary>Ответ</summary>

```
result: 9
result: 9
```

Исходный `x => x ** 2` — чистая функция. HOF-обёртка `withLog` добавляет побочный эффект (вывод в консоль) → `square` уже нечистая.

</details>

## Блок 2 — Иммутабельность

### Задача 6

```js
const state = Object.freeze({ tags: ['a', 'b'], count: 0 });
state.tags.push('c');
state.count = 99;
console.log(state.tags.length, state.count);
```

<details>
<summary>Ответ</summary>

```
3 0
```

`Object.freeze` **поверхностный**: примитив `count` защищён, а `tags` — ссылка на массив, который заморожен не был. Мутация массива проходит.

</details>

---

### Задача 7

```js
const prev = { scores: [1, 2, 3], user: 'Alice' };
const next = { ...prev, user: 'Bob' };
next.scores.push(99);
console.log(prev.user, prev.scores.length, next.user);
```

<details>
<summary>Ответ</summary>

```
'Alice' 4 'Bob'
```

Spread создаёт **поверхностную** копию: `prev.scores` и `next.scores` указывают на один и тот же массив.

</details>

---

### Задача 8

```js
const a = [3, 1, 2];
const sorted = a.sort((x, y) => x - y);

const b = [3, 1, 2];
const copy = [...b].sort((x, y) => x - y);

console.log(a === sorted, b[0], copy[0]);
```

<details>
<summary>Ответ</summary>

```
true 3 1
```

`Array.prototype.sort` сортирует **на месте** и возвращает тот же массив. `[...b].sort()` создаёт копию — `b` не тронут.

</details>

---

### Задача 9

```js
const setIn = (obj, [key, ...rest], val) =>
  rest.length === 0
    ? { ...obj, [key]: val }
    : { ...obj, [key]: setIn(obj[key], rest, val) };

const s = { a: { b: { c: 1 } } };
const t = setIn(s, ['a', 'b', 'c'], 42);
console.log(s.a.b.c, t.a.b.c, s === t, s.a === t.a);
```

<details>
<summary>Ответ</summary>

```
1 42 false false
```

Иммутабельное глубокое обновление: каждый узел **по пути** пересоздаётся через spread (structural sharing), ветки в стороне от пути не копируются.

</details>

---

### Задача 10

```js
const obj  = Object.freeze({ x: 1, nested: { y: 2 } });
const copy = Object.assign({}, obj);
copy.x = 99;
copy.nested.y = 99;
console.log(obj.x, obj.nested.y, copy.x);
```

<details>
<summary>Ответ</summary>

```
1 99 99
```

`Object.assign` делает поверхностную копию: примитив `x` скопирован по значению, `nested` — по ссылке. Заморозка `obj` не защищает `nested` в копии.

</details>

## Блок 3 — HOF: map / filter / reduce

### Задача 11

```js
console.log(['4', '8', '16'].map(parseInt));
```

<details>
<summary>Ответ</summary>

```
[4, NaN, 1]
```

`map` передаёт `(value, index)` → `parseInt` получает основание системы счисления:
- `parseInt('4', 0)` → `4` (base 0 → decimal)
- `parseInt('8', 1)` → `NaN` (base 1 невалидна)
- `parseInt('16', 2)` → `1` (base 2: `'1'` — валидный символ, `'6'` — нет, парсинг останавливается)

</details>

---

### Задача 12

```js
const result = [42].reduce((acc, x) => {
  console.log('called');
  return acc + x;
});
console.log('done:', result);
```

<details>
<summary>Ответ</summary>

```
done: 42
```

`reduce` с одним элементом и без `initialValue` возвращает этот элемент **не вызывая колбэк**. Колбэк нужен только когда есть хотя бы два значения.

</details>

---

### Задача 13

```js
const result = [1, 2, 3, 4, 5].reduce((acc, x) => {
  (x % 2 === 0 ? acc.even : acc.odd).push(x);
  return acc;
}, { even: [], odd: [] });
console.log(result.even, result.odd);
```

<details>
<summary>Ответ</summary>

```
[2, 4] [1, 3, 5]
```

`reduce` умеет строить не только числа, но и любые структуры. Аккумулятор — объект с двумя массивами.

</details>

---

### Задача 14

```js
const a = [1, 2, 3].map(x => [x, -x]).flat();
const b = [1, 2, 3].flatMap(x => [x, -x]);
console.log(a.join(',') === b.join(','), b);
```

<details>
<summary>Ответ</summary>

```
true [1, -1, 2, -2, 3, -3]
```

`flatMap(fn)` эквивалентен `map(fn).flat(1)`.

</details>

---

### Задача 15

```js
const map    = fn   => arr => arr.map(fn);
const filter = pred => arr => arr.filter(pred);
const pipe   = (...fns) => x => fns.reduce((v, f) => f(v), x);

const process = pipe(
  filter(x => x > 2),
  map(x => x * 3)
);
console.log(process([1, 2, 3, 4]));
```

<details>
<summary>Ответ</summary>

```
[9, 12]
```

Point-free стиль: `map` и `filter` возвращают функции, которые принимают массив. `pipe` выстраивает конвейер.

</details>

## Блок 4 — Каррирование и частичное применение

### Задача 16

```js
const f = (a, b, c = 0) => a + b + c;
const g = (...args) => args.length;
const h = (a, b, ...rest) => a + b;
console.log(f.length, g.length, h.length);
```

<details>
<summary>Ответ</summary>

```
2 0 2
```

`Function.length` считает только параметры **до** первого параметра с дефолтом или rest. Параметры с `= ...` и `...rest` не учитываются.

</details>

---

### Задача 17

```js
const curry = fn => function c(...a) {
  return a.length >= fn.length ? fn(...a) : (...b) => c(...a, ...b);
};
const greet = curry((greeting, name) => `${greeting}, ${name}!`);
const results = ['Alice', 'Bob', 'Carol'].map(greet('Hi'));
console.log(results);
```

<details>
<summary>Ответ</summary>

```
['Hi, Alice!', 'Hi, Bob!', 'Hi, Carol!']
```

`greet('Hi')` возвращает функцию `name => ...` — готовый колбэк для `map`.

</details>

---

### Задача 18

```js
function volume(l, w, h) { return l * w * h; }
const plank = volume.bind(null, 10, 5);
console.log(plank(3), plank.length);
```

<details>
<summary>Ответ</summary>

```
150 1
```

`bind` фиксирует первые аргументы. `.length` связанной функции = `fn.length - кол-во_привязанных_аргументов`.

</details>

### Задача 19

```js
const partial = (fn, ...pre) => (...args) => fn(...pre, ...args);
const divide  = (a, b) => a / b;
const half    = partial(divide, 10);
const third   = partial(divide, 15);
console.log(half(2), third(3), half(5));
```

<details>
<summary>Ответ</summary>

```
5 5 2
```

</details>

### Задача 20

```js
const curry = fn => function c(...a) {
  return a.length >= fn.length ? fn(...a) : (...b) => c(...a, ...b);
};
const mul       = curry((a, b, c) => a * b * c);
const double    = mul(2);
const quadruple = mul(2)(2);
console.log(double(3, 4), quadruple(5), mul(2)(3)(4));
```

<details>
<summary>Ответ</summary>

```
24 20 24
```

`double` и `quadruple` — независимые частичные применения. `double(3, 4)` передаёт оба оставшихся аргумента сразу.

</details>

## Блок 5 — Рекурсия

### Задача 21

```js
const flatten = arr =>
  arr.reduce((acc, x) =>
    Array.isArray(x) ? [...acc, ...flatten(x)] : [...acc, x], []);
console.log(flatten([1, [2, [3, [4]]]]));
```

<details>
<summary>Ответ</summary>

```
[1, 2, 3, 4]
```

Рекурсивный flatten без ограничения глубины: для каждого вложенного массива вызывает себя.

</details>

---

### Задача 22

```js
let calls = 0;
const fib = n => { calls++; return n <= 1 ? n : fib(n - 1) + fib(n - 2); };
fib(6);
console.log(calls);
```

<details>
<summary>Ответ</summary>

```
25
```

Без мемоизации число вызовов растёт экспоненциально: `fib(6)` = 25 вызовов, `fib(10)` = 177, `fib(20)` > 21 000.

</details>

---

### Задача 23

```js
const isEven = n => n === 0 ? true  : isOdd(n - 1);
const isOdd  = n => n === 0 ? false : isEven(n - 1);
console.log(isEven(6), isOdd(7), isEven(1));
```

<details>
<summary>Ответ</summary>

```
true true false
```

Взаимная рекурсия: функции вызывают друг друга. Базовый случай — `n === 0`.

</details>

---

### Задача 24

```js
const factorial = (n, acc = 1) => n <= 1 ? acc : factorial(n - 1, n * acc);
console.log(factorial(5), factorial(4));
```

<details>
<summary>Ответ</summary>

```
120 24
```

Аккумулятор позволяет писать рекурсию в хвостовой позиции — промежуточный результат передаётся аргументом, а не «висит» в стеке.

</details>

---

### Задача 25

```js
const deepCount = arr =>
  arr.reduce((acc, x) => acc + (Array.isArray(x) ? deepCount(x) : 1), 0);
console.log(deepCount([1, [2, 3], [4, [5, 6]]]));
```

<details>
<summary>Ответ</summary>

```
6
```

Считаем только «листья» (не массивы). `reduce` + рекурсия = обход дерева произвольной глубины.

</details>

## Блок 6 — Мемоизация

### Задача 26

```js
let count = 0;
const memo = fn => {
  const cache = new Map();
  return x => cache.has(x) ? cache.get(x) : (cache.set(x, fn(x)), cache.get(x));
};
const sq = memo(x => { count++; return x * x; });
sq(3); sq(4); sq(3); sq(4); sq(5);
console.log(count);
```

<details>
<summary>Ответ</summary>

```
3
```

Уникальных аргументов три: `3`, `4`, `5`. Повторные вызовы отдают кэш.

</details>

---

### Задача 27

```js
const memo = fn => {
  const cache = new Map();
  return x => cache.has(x) ? cache.get(x) : (cache.set(x, fn(x)), cache.get(x));
};
let calls = 0;
const fn = memo(obj => { calls++; return obj.n * 2; });
const obj = { n: 5 };
fn(obj);
fn(obj);
fn({ n: 5 });
console.log(calls);
```

<details>
<summary>Ответ</summary>

```
2
```

`Map` использует `===` для ключей. Первый `fn(obj)` — промах, второй — попадание (та же ссылка). Третий — новый объект `{ n: 5 }`, другая ссылка → снова промах.

</details>

---

### Задача 28

```js
let factor = 1;
const memo   = fn => { const c = {}; return x => x in c ? c[x] : (c[x] = fn(x)); };
const scaled = memo(x => x * factor);
console.log(scaled(5));
factor = 10;
console.log(scaled(5));
console.log(scaled(6));
```

<details>
<summary>Ответ</summary>

```
5
5
60
```

Мемоизировать нечистые функции опасно: для `5` вернётся устаревший кэш (`factor` изменился). Для нового аргумента `6` результат свежий.

</details>

---

### Задача 29

```js
const memo = fn => {
  const cache = new Map();
  return function memoized(n) {
    if (cache.has(n)) return cache.get(n);
    const r = fn(n);
    cache.set(n, r);
    return r;
  };
};
let calls = 0;
const fib = memo(n => { calls++; return n <= 1 ? n : fib(n - 1) + fib(n - 2); });
console.log(fib(5));
console.log(calls);
```

<details>
<summary>Ответ</summary>

```
5
6
```

Без мемоизации `fib(6)` = 25 вызовов (задача 22). С мемоизацией `fib(5)` = 6 — каждое уникальное значение от `0` до `5` вычисляется ровно один раз.

</details>

## Блок 7 — Замыкания и фабрики

### Задача 30

```js
function makeCounter(start = 0) {
  let n = start;
  return { inc: () => ++n, dec: () => --n, val: () => n };
}
const c1 = makeCounter(10);
const c2 = makeCounter();
c1.inc(); c1.inc(); c2.inc();
console.log(c1.val(), c2.val());
```

<details>
<summary>Ответ</summary>

```
12 1
```

Каждый вызов `makeCounter` создаёт **новое** замыкание с независимой переменной `n`. `c1` и `c2` не делят состояние.

</details>
